# forge-lint Configuration

Fails a repo when its forge.yaml carries a stale engine URI, a missing hack script, or a missing required field.

> Full OpenAPI specification: [spec.openapi.yaml](../spec.openapi.yaml)

## Fields

### `rootDir`

- **Type:** `string`
- **Required:** No
- **Description:** Root directory holding the forge.yaml and the src tree to check (default is current directory)
