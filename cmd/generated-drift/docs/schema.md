# generated-drift Configuration

Fails a repo when a build that starts with no artifact store changes a file git tracks or does not ignore.

> Full OpenAPI specification: [spec.openapi.yaml](../spec.openapi.yaml)

## Fields

### `rootDir`

- **Type:** `string`
- **Required:** No
- **Description:** The repo directory holding the forge.yaml to build. Defaults to the root forge sends.
